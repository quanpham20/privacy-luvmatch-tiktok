2. TikTok Login Kit & Scopes Used

LuvMatch offers TikTok Login Kit (OAuth 2.0) under Client Key awfojt5u0tl4q8ho to allow users to authenticate quickly and securely. During TikTok Login, we request only the essential permissions:

Scope Requested Data Collected Purpose of Processing

No Unauthorized Posting or Access: LuvMatch does NOT request permission to publish videos, modify your TikTok profile, view private videos, or access direct messages. We strictly access read-only public profile data to authenticate you.

Strict Prohibition on Selling Data: We strictly NEVER sell, rent, monetize, or transfer your TikTok data to data brokers, ad exchanges, or unauthorized third parties for marketing purposes.

4. TikTok User Data Deletion Instructions

In accordance with TikTok Developer Policies and global data protection regulations (GDPR/CCPA), users have the right to request the deletion of all data acquired through TikTok Login at any time. You can choose any of the following options:

Option A: Revoke Access via TikTok Mobile App

  1. Open the TikTok app on your mobile device.
  2. Go to your Profile > tap the Menu (3 lines) in the top right > select Settings and privacy.
  3. Select Security & permissions > tap Manage app permissions.
  4. Locate LuvMatch in the list of authorized applications.
  5. Tap on LuvMatch and select Remove access. This immediately revokes LuvMatch’s access to your TikTok credentials.

Option B: Permanent Account Deletion in LuvMatch App

  1. Launch the LuvMatch application.
  2. Go to Profile > Settings.
  3. Scroll to the bottom and select Delete Account Permanently.
  4. Confirm deletion. All synced photos, match records, chat logs, and TikTok IDs will be purged immediately from our active database.

Option C: Direct Support Request

Send an email to our developer team with the subject “TikTok Data Deletion Request - LuvMatch”:

5. Data Storage, Retention & Security

All data transmitted between LuvMatch and our backend servers (auth.ubiw.space) is strictly encrypted in transit using HTTPS / TLS 1.3 protocols.

TikTok authentication tokens and identifiers are retained only as long as you maintain an active account. Upon deletion, data is removed immediately from active servers, and backup copies are completely erased within 30 days.
